# StudyFlow — AI Study Assistant

A React application that transforms notes or topics into interactive flashcards and multiple-choice quizzes using AI.

## Features

- Generate AI-powered flashcards.
- Flip flashcards to reveal answers.
- Track mastered flashcards.
- Generate multiple-choice quizzes.
- Check quiz scores and explanations.
- Retest incorrect answers.
- Responsive mobile-friendly interface.
- Error handling and retry functionality.

## Technologies Used

- React.js
- Node.js
- Express.js
- Groq AI API
- JavaScript
- CSS
- Vite

## Installation and Setup

1. Install Node.js 18 or newer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install dependencies:

   `npm install`

5. Create a `.env` file in the root directory:

   `GROQ_API_KEY=your_actual_api_key`

   `PORT=3001`

6. Start the application:

   `npm run dev`

7. Open `http://localhost:5173`.

## AI Usage Note

AI assistance was used during development to help generate and explain parts of the application. The code should be reviewed and understood by the developer.

## Known Limitations

- Requires an internet connection.
- Requires a valid Groq API key.
- AI-generated answers may need verification.
- Study sessions are not permanently saved.
